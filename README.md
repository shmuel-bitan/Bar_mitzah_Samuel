# Prototype d’invitation animée

Ouvrez `index.html` dans un navigateur récent.

## Fichiers

- `index.html` : structure de la page
- `style.css` : design responsive et animation 3D
- `script.js` : ouverture, particules, rejeu et personnalisation
- `assets/carte-samuel.jpg` : visuel de l’invitation

## Personnaliser le nom du destinataire

Ajoutez `?guest=Prénom Nom` à l’adresse de la page. Exemple :

```text
index.html?guest=Famille Cohen
```

Le bouton final est volontairement en mode démonstration. Lors de l’intégration au site existant, il devra révéler ou rejoindre la section RSVP.
